# Segurança

Não abra issue pública contendo credenciais, dados financeiros, documentos pessoais, payloads bancários ou chaves de API.

Reporte vulnerabilidades diretamente ao mantenedor do repositório, incluindo versão, impacto, passos mínimos para reprodução e evidências anonimizadas.

Nunca envie no relatório:

- `.env` real;
- backup real;
- certificado privado;
- token Cloudflare;
- credencial bancária;
- API key Evolution;
- senha SMTP;
- dados completos de clientes.
